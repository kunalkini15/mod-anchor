# Privacy Policy

ModAnchor stores moderation review data needed to run the app.

This may include moderator usernames, action details, review status, timestamps, reports, and related post/comment/user references.

ModAnchor does not sell user data. It does not use LLMs in the current MVP.

The data is used only to support moderator onboarding, approval workflows, monitoring, reports, and app functionality.

Regular community members should not have access to the private ModAnchor workspace.
